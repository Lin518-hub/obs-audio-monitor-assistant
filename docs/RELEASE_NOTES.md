- 新增多套开播方案，保存和切换软件、网页、投影设置及窗口布局。
- 合并重复的一键准备请求，复用本次运行中助手打开过的网页；只显示需要处理的问题。
- 浮窗右键支持锁定、透明度、临时静音倒计时及返回主界面；静音期间检测继续，到期恢复提醒。
- 修复未保存布局时误报成功、方案操作并发、异常方案数据及取消后继续确认的问题。
- 窗口恢复增加有限重试，配置页增加三步引导。

## v3.9.12

- 首次配置增加说话验证、实际报警确认、开播工作台配置和试运行。
- 未连接 OBS、未验证音源或提醒时，不再宣称设置完成；可以暂存并从主界面继续配置。
- 新安装默认只选择 OBS；可按需添加软件、启用投影和保存位置，保留已有用户配置。
- 仅使用音频检测的用户可明确跳过开播工作台。
- 连接、直播间名称保存和引导完成保存失败时显示重试提示；名称统一要求 2～60 个字符。
- 明确区分工作台准备、音频检测和 OBS 推流。

## v3.9.11

- 一键开播显示全屏浅绿色遮罩和居中进度卡片，显示当前步骤及耗时；按钮或 Esc 可交回操作权并停止后续自动操作，保留已打开的软件。
- 遮罩覆盖所有显示器，完成、失败、界面异常或 3 分钟超时自动解除。
- 窗口布局逐项显示保存和恢复结果，支持单独保存、恢复及只重试失败步骤；恢复后读取实际窗口位置进行确认。
- 修复已运行软件单独恢复无效、重试浏览器重复打开页面，以及流程结束后投影延迟移动的问题。
- 启动请求发出后确认程序运行状态；界面显示简短处理建议，详细命令错误保留在日志。
- 新增浮窗锁定及 30%～100% 不透明度设置，浮窗提供快速锁定/解锁按钮。

## v3.9.9

- 一键开播增加毛玻璃启动进度弹窗，实时显示当前启动/恢复步骤，支持收起后台继续；完成自动收起，失败显示原因。

- 一键开播：改善 OBS 中文“投影－输出”识别；布局保存立即落盘；OBS 启动完成后再打开投影，手动重试支持启动 OBS。
- 勾选“OBS 投影－输出（启动并恢复）”同时启用自动打开。请先摆放好投影，再保存当前布局。
- 默认使用经典绿色，设置 → 系统与更新可切换经典绿/暖黄色；图标、按钮与导航同步变色。
- 小浮窗支持拖动边角持续按比例缩放，修复圆角透明底层和多功能布局。
- 连续静音满 3 秒闪一次红色描边，恢复说话闪绿色。
- 开启虚拟摄像头时询问是否开始检测，5 秒后关闭提示；只有确认才开始检测。
- 完善窗口动画、下拉菜单和状态显示。

包含 Windows x64 安装包及 Mac ARM64 压缩包。Windows 多显示器与不同 DPI 环境仍建议按实际直播布局确认位置。
