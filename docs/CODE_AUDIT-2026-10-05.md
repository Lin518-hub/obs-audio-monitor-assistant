# 本地代码审计（2026-10-05）

## 范围

重点审阅当前未发布改动：一键开播、浏览器复用、窗口确认/布局恢复、方案存储与切换、浮窗菜单和临时静音；同时执行桌面与远程服务端全量测试，检查类型、构建和差异格式。未触碰线上部署，不生成安装包。

## 本次发现并修复

1. 手动选窗可跨软件选择，但恢复只搜索目标软件进程，导致保存成功后无法正确恢复。改为限定目标软件窗口；确认后检查进程/句柄归属并重读位置。识别不到目标软件时提示重新配置程序路径。
2. 保存/切换/删除方案未互斥，快速点击可能发送相互覆盖的配置。增加同步执行锁和忙碌状态，并阻止方案操作期间的一键启动。
3. 配置加载未过滤空标识、空名称、重复标识和非对象方案设置。增加规范化与去重，并补充损坏数据回归。
4. 保存布局捕获取消异常后仍可能进入下一项目。每个后续项目及投影处理前检查取消状态，停止继续弹出确认。
5. 窗口选择对话框异常返回索引未处理。改为安全跳过。

## 仍有边界

当前机器是 macOS，本轮未实测 Windows 的窗口高亮、多屏 DPI、管理员权限软件和真实 OBS 投影。浏览器去重只记录本次进程运行中助手打开的页面，不能读取外部浏览器所有标签页或确认标签页已手动关闭。自动化通过不等于全部运行场景无缺陷；不作“零错误”保证。
