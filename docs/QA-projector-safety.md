# OBS 投影安全区（2026-10-07，本地开发）

入口：设置 → 连接与设备 → 投影安全区。默认关闭，不改 OBS 场景或视频输出。

- 使用独立透明、鼠标穿透窗口，只覆盖投影客户区内按画布比例居中适配的视频。
- Windows 常驻辅助进程约每 80ms 读取窗口状态。拖动/缩放或尺寸位置变化立即隐藏，稳定至少 280ms 后重新对齐。最小化、关闭、遮挡、辅助进程无响应时隐藏。
- 多投影要求手动选择；保存标题以便重开后识别。相同标题多个窗口必须再次明确选择。
- 源画布默认 1080×1920；左右参考 iPhone 18 Pro Max 1320×2868，可选 Pro 1206×2622；上下参考 Pura X View 1320×2232。尺寸、裁切微调、灰色遮罩深浅、标记可调整。
- 居中铺满计算：左右各 `(1 - phoneRatio/sourceRatio)/2`，上下各 `(1 - sourceRatio/wideRatio)/2`，负值取零。默认约 9.09% / 2.44%。不模拟直播平台按钮、圆角或平台自身视频适配规则。
- 自动跟随暂支持 Windows；macOS 能编辑保存配置和预览，明确显示平台限制。
