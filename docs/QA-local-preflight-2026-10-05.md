# 本地功能检查与一键开播改进

本次仅修改本地代码，版本保持 3.9.12，不打包、不推送触发发布。

## 已修复

- 勾选软件位置恢复但未保存布局时，不再把准备结果判为全部成功；按项目提示保存或关闭恢复。
- 自动准备投影时，缺少所需位置会提示打开投影、摆放、保存；仍可通过单独打开投影完成配置。
- 软件启动窗口被替换或位置未保持时，重新枚举窗口并有限重试恢复，最多三次；每次受原有等待时限和取消检查约束，不重新启动软件。
- 已取消参与的项目不再进入失败重试列表；投影禁用后的历史结果清除。
- 保留仅显示问题的结果区域；增加可折叠的三步配置说明。

## 验证范围

本地全量自动化：171 通过、1 项 Windows 原生测试跳过。覆盖音频与静音判定、报警时序、OBS 状态、断线重连、配置迁移、浮窗尺寸/形状、窗口布局坐标、启动恢复、更新状态与 ATEM 等逻辑。
新增回归验证：勾选恢复但没有布局时返回恢复失败，而非假成功。
本机为 macOS，未据此宣称 Windows 原生窗口、OBS 插件弹窗、权限提升、多屏热插拔等已实机通过。

## 建议后续补充

- 一键导出脱敏诊断包：包含失败步骤、版本、屏幕布局与错误原因，不包含 OBS 密码。
- 多套工作台方案：按直播间或显示器组合保存，并支持快速切换。
- 配置迁移预览：更换电脑后先检测失效路径和缺失显示器，再让用户确认映射。

## Windows 实机验收

1. OBS 已运行/未运行、浏览器已运行、输出投影已打开分别执行准备，核对窗口与布局。
2. 慢启动、启动时主窗口替换、路径失效、WebSocket 密码错误、OBS 权限高于助手时，确认问题可见且其他步骤继续。
3. 位置未保存时先单独打开、摆放保存，再准备；恢复失败只重试对应步骤。
4. 恢复期间接手操作，确认后续窗口不再移动；取消参与的项目不被重试。
5. 双屏负坐标、缩放比例不同、断开原显示器后验证位置回落。

## 后续四项功能（同日本地开发）

- 保存布局前逐项用绿色边框高亮目标窗口，通过系统对话框确认；可跳过或从当前窗口列表分页手动选择。确认后重新读取窗口位置，窗口关闭则不保存，跳过保留原记录。窗口标题随布局保存，恢复时优先匹配。
- 开播检查页增加折叠方案管理：保存、切换、删除，最多 20 套；只保存程序/网址、投影设置和窗口布局，不保存 OBS 密码。修改后另存新方案。
- 一键准备的并发请求合并；失败后可以重新发起。已存在投影沿用原有复用逻辑。助手本次运行中已打开过的相同浏览器程序/网址组合不重复打开；切换到新网址会打开一次。不能探测外部浏览器标签页是否后来关闭，仍可通过“打开直播页面”手动打开；助手启动前已打开的网页也不能可靠识别。
- 浮窗原生右键菜单支持锁定、30–100% 透明度、1/5/15 分钟临时静音、立即恢复与回到主界面。覆盖普通内容与 Windows 拖动区域右键；临时静音隐藏音频/机位提醒，检测继续，显示秒级倒计时，到期主动刷新提醒，重启不保留静音。
