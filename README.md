# OBS 音频检测助手 · 离线开源最终版

这是独立的离线版本，保留本机音频检测、静音提醒、浮窗、一键开播工作台、OBS 投影安全区和局域网 ATEM 控制。

## 网络边界

- OBS 仅连接本机 `127.0.0.1`，需要开启 OBS WebSocket，填写端口和密码。
- ATEM 仅连接局域网 IPv4 地址，不解析公网域名。
- 无监控服务器、数据上报、手机远程控制、联网版本检查或自动更新。
- 不内置直播网页启动功能。用户手动启动的其他软件有自己的网络行为，不由本工具控制。
- 源码构建时安装 npm 依赖需要网络；安装好的软件无需互联网。

## 安装与使用

安装包与内部联网版使用不同的应用标识、快捷方式及数据目录，可并存，不迁移内部版凭据。

Windows 支持投影跟随和工作台窗口布局；macOS 支持音频检测、设置和投影预览。投影安全区记住上次开关状态，等待 OBS 投影出现后自动对齐。

## 开发

需要 Node.js 22：

```sh
npm ci
npm test
npm run build
npm run dev
```

构建安装包：Windows 主机运行 `npm run dist:win`；Apple Silicon Mac 运行 `npm run dist:mac`。

这是公开项目的最终离线版本。内部联网软件的后续开发和更新不在此仓库发布。历史公开版本保留其当时的许可证和内容，本版本许可证不自动改变第三方或历史文件的授权。
